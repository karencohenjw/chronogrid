# ChronoGrid

Temporal chaos and calendar conformance lab for testing DST, RRULE, ICS, ISO weeks, Julian dates, timezone transitions, leap years and calendar edge cases.

Developed by [JW Calendar](https://jwcalendar.com/).

## Status

ChronoGrid is under active development.

The first release will provide deterministic temporal test cases and a containerized command-line interface for reproducing difficult date and time bugs.
