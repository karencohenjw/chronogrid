# ChronoGrid v0.2.0

ChronoGrid 0.2.0 adds local DST gap/fold classification, timezone event matrices with explicit fold selection, bounded RFC recurrence expansion, a diagnostic ICS subset auditor, and date-time ICS recurrence expansion. It also adds runtime diagnostics, schema-versioned JSON reports, expanded documentation, and native Windows x64/x86 release archives.

The ICS auditor deliberately documents its supported subset and does not claim complete RFC 5545 compliance. The release workflow publishes SHA-256 checksums alongside both Windows archives.
